# ❌ Tic-Tac-Toe AI Game ⭕

A modern, responsive browser-based Tic-Tac-Toe game built with HTML, CSS, and vanilla JavaScript. Features an unbeatable AI opponent powered by the Minimax algorithm.

🎮 **[Play the Live Game Here](https://tictactoex36.netlify.app)**

## 🌟 Features
- **Multiple Game Modes:** Play against the AI or challenge a friend locally (2-player mode).
- **3 AI Difficulty Levels:** 
  - **Easy:** Makes random moves.
  - **Medium:** Mix of random and strategic moves.
  - **Unbeatable:** Powered by the Minimax algorithm for optimal decision-making.
- **Responsive Design:** Dark-mode UI optimized for desktop and mobile browsers.

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox & Grid layout)
- JavaScript (ES6+ & Minimax AI)****
